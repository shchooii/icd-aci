# 실시간 데모 추론 서버

`/demo` 페이지가 부르는 서버입니다. 판독문 한 건을 받아 파이프라인을 돌리고, 결과를 예시 화면과 같은 형식(노트 원문의 근거, 개념별 후보, 제안 코드)으로 돌려줍니다.

항상 켜 둘 필요는 없습니다. 쓸 때 켜고, 꺼져 있으면 페이지 맨 아래에 "서버 꺼짐"이라고만 나옵니다. 페이지에는 서버 주소, 켜는 방법, 설정 칸이 없습니다.

## 돌아가는 단계

| 단계 | 하는 일 | 모델 |
|---|---|---|
| 1. 개념 추출 | 노트에서 개념, 검색어, 인용을 뽑고, 인용이 노트의 어디에 있는지 찾습니다. | 생성 모델 (Qwen3-8B) |
| 2. 후보 검색 | 132개 라벨의 코드명을 노트에 비춰 점수를 매겨 50개를 남기고, 남은 50개를 각 검색어에 비춰 어느 개념의 후보인지 정합니다. | 재정렬 모델 (Qwen3-Reranker-8B) |
| 3. 코드 선택 | 노트, 라벨 목록, 추출 개념, 후보를 주고 코드를 고르게 합니다. | 생성 모델 |

- 프롬프트와 샘플링 값은 실험과 같습니다(`system_prompt_extract.txt`, `system_prompt_aci132.txt`, temperature 0.6, top-p 0.95, top-k 20, seed 42).
- 재정렬 점수 계산도 실험과 같은 방식입니다(`rerank_service.py`).
- 실험과 다른 점: 실험은 계층 탐색과 색인 검색의 결과를 모은 뒤 재정렬했고, 여기서는 132개 라벨 전체를 바로 재정렬합니다. 이 라벨 목록에서는 모은 결과가 이미 거의 전체였습니다. 임베딩 모델은 쓰지 않습니다.
- 검증 단계는 없습니다.
- `ICD_DEMO_PIPELINE=G`로 두면 3단계만 돌립니다(재정렬 모델 불필요, GPU 한 장).

### 실행 방식 두 가지

| 방식 | 하는 일 | 걸리는 시간 |
|---|---|---|
| 실험과 같은 설정 (`full`, 기본) | 추출과 코드 선택 모두 모델이 추론한 뒤 답합니다. | 짧은 노트는 1분 안팎, 긴 노트는 2~3분 |
| 빠르게 (`fast`) | 추론을 생략합니다. | 수십 초 |

논문에 실린 수치는 모두 `full` 설정의 결과입니다. `fast`의 정확도는 확인하지 않았습니다.

## 필요한 것

- 24GB GPU 두 장: 한 장에 생성 모델, 한 장에 재정렬 모델.
- 생성 모델: OpenAI 호환 서비스(vLLM 등). 한 장에 올릴 때는 `--tensor-parallel-size 1 --max-model-len 32768`.
- 재정렬 모델: `rerank_service.py`를 torch와 transformers가 있는 환경에서 실행합니다.

```sh
ICD_DEMO_RERANKER_PATH=<재정렬 모델 폴더> CUDA_VISIBLE_DEVICES=<GPU> python server/rerank_service.py
```

두 모델 주소는 이 서버 안이나 사설망 주소만 받습니다. 공인 주소를 넣으면 서버가 시작을 거부합니다.

## 켜고 끄기

### 쓰는 동안만 켜기 (권장)

내 컴퓨터의 터미널에서 한 줄을 실행합니다. 서버가 켜지고, 같은 접속으로 브라우저와 연결(SSH 터널)됩니다.

```sh
ssh -tt -o ServerAliveInterval=15 -o ServerAliveCountMax=3 -L 8765:127.0.0.1:8765 <계정>@<서버> 'exec sh <저장소 경로>/server/demo.sh run'
```

그 창을 열어 둔 동안 데모가 실행됩니다. `Ctrl+C`를 누르거나 SSH 서버가 연결 종료를 감지하면 데모와 해당 실행이 띄운 모델이 내려갑니다. 모델이 시작 중이었다면 시작 명령의 등록이 끝난 뒤 정리합니다.

### 켜 두고 나가기

| 명령 | 하는 일 |
|---|---|
| `sh server/demo.sh start` | 백그라운드로 켭니다. 로그아웃해도 계속 켜져 있습니다. |
| `sh server/demo.sh stop` | 끕니다. |
| `sh server/demo.sh restart` | 껐다 켭니다. 설정을 바꾼 뒤에 씁니다. |
| `sh server/demo.sh status` | 켜져 있는지, 두 모델이 응답하는지, 자동 종료까지 남은 시간을 보여 줍니다. |

이 경우 쓰는 사람은 터널만 엽니다: `ssh -N -L 8765:127.0.0.1:8765 <계정>@<서버>`

### 저절로 꺼지게 하기

`server/demo.env`에 `ICD_DEMO_IDLE_EXIT_MIN=60`처럼 적으면, 판독문 요청이 60분 동안 없을 때 서버가 스스로 꺼집니다. 0이면 꺼지지 않습니다.

### 모델도 같이 켜고 끄기 (선택)

GPU를 쓰는 것은 모델 서비스입니다. `server/demo.env`에 두 명령을 적어 두면 데모 서버와 같이 움직입니다.

```sh
ICD_DEMO_MODEL_START_CMD='sh /경로/start_models.sh'   # run, start 때 실행. 바로 돌아오는 명령이어야 합니다.
ICD_DEMO_MODEL_STOP_CMD='sh /경로/stop_models.sh'     # stop, run 종료, 자동 종료 때 실행.
```

모델이 올라오는 몇 분 동안 페이지는 "서버 켜짐 · 모델 준비 중"을 보여 주다가, 두 모델이 모두 준비되면 "서버 켜짐"으로 바뀝니다.

모델을 내리는 명령은 모델을 띄운 프로세스 묶음 전체를 내려야 합니다. 맨 위 프로세스만 죽이면 모델 프로세스가 남아 GPU를 계속 잡습니다(`pkill -s <세션 번호>`처럼 세션 단위로 내리면 됩니다).

## 처음 한 번 하는 설정

```sh
cp server/demo.env.example server/demo.env   # 모델 주소 등을 고칩니다
```

페이지 주소가 바뀌면 `ICD_DEMO_ORIGINS`에 새 주소를 추가합니다.

## 접근

접근 토큰은 기본으로 쓰지 않습니다. 서버가 켜져 있으면 연결된 사람은 누구나 쓸 수 있고, 서버를 끄면 아무도 쓸 수 없습니다. 접근은 서버를 켜고 끄는 것으로 조절합니다.

서버는 기본으로 이 컴퓨터 안(`127.0.0.1`)에서만 듣기 때문에, SSH 터널을 연 사람만 닿습니다. 페이지 주소만 아는 사람에게는 "서버 꺼짐"으로 보입니다.

토큰으로 막고 싶을 때만 `ICD_DEMO_REQUIRE_TOKEN=1`을 적습니다. 그러면 `sh server/demo.sh link`가 토큰이 든 링크(`…/demo#token=…`)를 보여 주고, 그 링크로 한 번 연 브라우저만 쓸 수 있습니다.

## 페이지에 보이는 것

- 위쪽의 예시 1·2·3: 지어낸 판독문 세 건(당뇨·고혈압 추적, 무릎 인대 손상, 심부전·심방세동). 벤치마크의 노트가 아닙니다.
- 실행하면 세 단계의 진행 상황이 차례로 나오고, 끝나면 예시 화면과 같은 검토 화면으로 바뀝니다.
- 맨 아래의 서버 상태 한 줄:

| 표시 | 뜻 |
|---|---|
| 서버 켜짐 | 실행할 수 있습니다. |
| 서버 꺼짐 | 서버가 꺼져 있거나 터널이 닫혀 있습니다. |
| 서버 켜짐 · 모델 준비 중 | 모델 서비스가 꺼져 있거나 올라오는 중입니다. |
| 서버 켜짐 · 접근 권한 없음 | 토큰을 쓰도록 설정했을 때만 나옵니다. |

페이지는 꺼져 있을 때 10초마다, 켜져 있을 때 30초마다 다시 확인합니다.

브라우저가 "로컬 네트워크 접근"을 물으면 허용해야 합니다. Safari는 이 연결을 막을 수 있으니 Chrome, Edge, Firefox를 권장합니다. 계속 막히면 터널을 연 채 `http://127.0.0.1:8765/demo`로 엽니다(서버가 직접 내주는 같은 페이지).

## 공개 저장소에 올리기 전에

```sh
sh server/check_public.sh
```

올라갈 파일에 서버 주소(IP), 실제 계정이 적힌 접속 명령, 토큰, 서버별 설정 파일이 섞여 있으면 알려 주고 실패합니다. 서버 주소는 저장소 어디에도 적지 않고, 페이지 화면에도 나오지 않습니다.

## 지키는 것

- 판독문과 모델 응답은 메모리에만 있습니다. 파일에 쓰지 않고, 로그에는 시각·요청 종류·상태 코드만 남습니다.
- 끝난 작업은 페이지가 결과를 읽는 즉시 지웁니다. 읽지 않은 결과도 15분 뒤에 지웁니다.
- 허용 목록에 없는 페이지 주소의 요청은 거절합니다.
- `server/demo.env`, 토큰 파일, 로그 파일은 git에 올라가지 않습니다(`.gitignore`).

## 요청 형식

| 요청 | 응답 |
|---|---|
| `GET /api/health` | 연결 상태, 방식, 단계 목록, 두 모델의 준비 여부 |
| `POST /api/predict` `{"note": "...", "mode": "full"}` | `202 {"job_id": "..."}` |
| `GET /api/jobs/<id>` | `queued` / `running`(지금 단계) / `done`(검토 화면용 결과) / `error`(오류 코드와 멈춘 단계) |
| `DELETE /api/jobs/<id>` | 취소 |
